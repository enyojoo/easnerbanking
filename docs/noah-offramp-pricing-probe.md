# Noah offramp pricing probe

Generated by [`business/scripts/probe-noah-offramp-pricing.ts`](../business/scripts/probe-noah-offramp-pricing.ts) and Noah MCP validation.

**Last probe:** 2026-06-05 (prod `/prices`, read-only)

## How to run

```bash
cd business && node --env-file=.env.local --import tsx scripts/probe-noah-offramp-pricing.ts
```

Required env for **prepare** probes:

- `PROBE_NOAH_CUSTOMER_ID` — Noah business customer
- `PROBE_NOAH_RECIPIENT_ID` — NGN bank recipient (Easner `recipients.id`)
- Optional: `PROBE_NOAH_RECIPIENT_ID_RWF_BANK`, `PROBE_NOAH_RECIPIENT_ID_RWF_MOBILE`

Without recipient env vars the script runs **prices-only** mode (live `/prices` per ticket).

## Decision gate (implemented)

| Finding | Action |
|---------|--------|
| prepare `Breakdown.ChannelFee` present | **2A** — use prepare breakdown for `channelCost` (`global-payout-pricing.ts`) |
| DB mid at $100 vs ticket `/prices` mid diverges | **2B** — ticket-sized mid at quote (`payout-quote.ts` → `noahImpliedProviderRate`) |
| `channelCost` ≈ settlement `ChannelFee` | Settlement webhook reconcile (`reconcile-payout-margin.ts`) |
| Merchant schedule << live Channel | Log `channel_cost_vs_schedule`; do **not** show schedule in UI |
| ₦100k noahFloor ~$80, channel ~$6 | Use prepare `ChannelFee` at quote — `/prices` channel unvalidated at settle |
| Exchange fee = ChannelFee only | `channelCost = prepareChannelFee ?? (noahFloor − mid − margin)` |
