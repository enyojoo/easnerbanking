See [Easner Dev Platform](/).

Easner holds each customer in a **custodial stablecoin vault** (USDC for USD, EURC for EUR, on Solana). Virtual-account deposits convert into that vault. Wallet addresses are the vault’s token account. Sends leave from the same vault to bank, mobile money, on-chain, or Easetag.

Checkout is separate: collect onto **your** business balance.
