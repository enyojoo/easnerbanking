A quote locks what you send and what the destination receives. Create a quote, then execute it with a transfer before it expires.

Quotes expire **15 minutes** after create. Expired quotes cannot be transferred.

<Note>
  **Scope:** `transfers.write`
</Note>

## Object

| Field | Type | Notes |
|---|---|---|
| `id` | string | `qt_…` |
| `source` | string \| null | `acct_…` |
| `destination` | string \| null | `dest_…` |
| `send` | `{ amount, currency }` | What leaves the platform account, cents |
| `receive` | `{ amount, currency }` | What the destination should get, cents |
| `expires_at` | ISO-8601 | |
| `status` | string | `open` until used or expired |
| `livemode` | boolean | |

```json
{
  "id": "qt_…",
  "source": "acct_…",
  "destination": "dest_…",
  "send": { "amount": 4900, "currency": "USD" },
  "receive": { "amount": 4900, "currency": "USD" },
  "expires_at": "2026-09-20T00:15:00.000Z",
  "status": "open",
  "livemode": false
}
```

In test, send and receive are 1:1. In live, a wallet destination may return a higher `send.amount` (fees) and a different `receive.currency`. Always debit `send.amount`.

## Create

```bash
curl https://api.easner.com/v1/quotes \
  -H "Authorization: Bearer $EASNER_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 4900,
    "currency": "usd",
    "receive_currency": "usd",
    "source": "acct_…",
    "destination": "dest_…"
  }'
```

| Field | Required | Notes |
|---|---|---|
| `amount` | yes | Positive integer cents |
| `currency` | no | Defaults to `USD` |
| `receive_currency` | no | Defaults to send currency |
| `source` | no | Platform account to debit |
| `destination` | no | Destination to credit |

`201`. `400` `invalid_amount` if `amount` is not a positive integer. `400` `create_failed` if pricing cannot be built.

The body has no `recipientId` or `formSessionId`.

## Expected

- Show `send` and `receive` to your user before you transfer.
- If the quote is expired, create a new one. Do not reuse the id.
- Then [Transfers](/transfers) with `{ "quote": "qt_…" }`.
