Dev is **Console** plus **platform `v1`**.

Base URL: `https://api.easner.com`

Auth: `Authorization: Bearer easner_sk_test_…` or `easner_sk_live_…`

Amounts are minor units (cents). Errors are `{ error: { type, code, message } }`. Writes that move money take `Idempotency-Key`.

## Expected flow

<Steps>
  <Step title="Open Dev">
    Switch to Dev on `business.easner.com`.
  </Step>
  <Step title="Mint a test key">
    Open Console. Mint a test key. Add a webhook URL and tick events.
  </Step>
  <Step title="Create objects">
    Create a customer. Open a USD (or EUR) account. Add a destination.
  </Step>
  <Step title="Quote, then transfer">
    Fulfil from `transfer.completed` and `transaction.created`.
  </Step>
  <Step title="Collect (optional)">
    Add a website on Checkout, create sessions from your server, mount `checkout.js`, fulfil from `checkout.completed`.
  </Step>
  <Step title="Go live">
    Mint a live key only after test works. Live debits and credits the platform book.
  </Step>
</Steps>
