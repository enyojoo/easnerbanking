# Third-Party Assets

## Crypto and Network Icons

This project uses externally hosted icon assets for recipient wallet dropdowns.

- **Cryptocurrency Icons**
  - Source: https://github.com/spothq/cryptocurrency-icons
  - Usage: token logos (`USDT`, `USDC`, `EURC`, `BTC`, `SOL`, `PYUSD`)
  - License: See upstream repository license and terms.

- **Trust Wallet Assets**
  - Source: https://github.com/trustwallet/assets
  - Usage: network logos (`Base`, `Bitcoin`, `Celo`, `Ethereum`, `FlowEvm`, `Gnosis`, `Lightning`, `Solana`, `Tron`)
  - License: See upstream repository license and terms.

Before shipping to production, review both upstream licenses and trademark terms for any required attribution or usage constraints.
